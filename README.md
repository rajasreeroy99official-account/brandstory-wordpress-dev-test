# BrandStory — Digital Marketing Agency in Abu Dhabi

GitHub-ready WordPress custom theme based on the supplied assessment assets and Figma screenshots.

## Installation
1. Extract this repository into `wp-content/themes/brandstory-abu-dhabi/`.
2. Activate **BrandStory Abu Dhabi** from WordPress → Appearance → Themes.
3. Create/assign the Primary Menu, or use the built-in fallback menu.
4. Set a static homepage if required by the WordPress installation.

## Included
- Responsive desktop/tablet/mobile layout
- Hero section with supplied background asset
- About section
- SEO / SMM / PPC service cards
- Expandable strategy accordion
- Partner/trust section
- Statistics
- Team carousel
- FAQ accordion
- Case-study carousel
- Footer
- Other-location links
- No external JS/CSS framework required

## Assessment
The supplied assessment asks for a responsive WordPress page matching the Figma design, with clean code, responsive behavior, hover/basic interactions, optimized assets and functional links/buttons.

## Notes
The image assets supplied with the assessment are included under `assets/images/`. Text and layout are implemented as WordPress/PHP/HTML/CSS rather than using a single screenshot as the page.
